## Sobre o Projeto

Este site é meu portfólio profissional focado no desenvolvimento front-end para a área da saúde. Ele serve para apresentar meus projetos, habilidades técnicas e experiências na criação de interfaces modernas, acessíveis e intuitivas para sistemas médicos e clínicas.
